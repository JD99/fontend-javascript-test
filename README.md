# Тестовое задание на позицию frontend-разработчик

### Задание 1

Написать код для создания указанного числа пространственных объектов. 

1. У каждого объекта должна быть следующая атрибутивная информация: id (int), name (text), area (float), status (bool), date_create (date), type (int). 
2. Атрибутивная информация и координаты объекта создаются случайным образом в соответсивии с таблицей ниже. Тип геометрии - точка (Point).
3. На выходе должен получиться один json объект (FeatureCollection), формат данных согласно https://geojson.org/. 

**Пример атрибутивных данных**
```
+------+------------+-----------+---------+-------------+---------------+
| id   | name       | area      | status  | date_create |      type     |
+------+------------+-----------+---------+-------------+---------------+
| 1    | Точка №123 | 35,002    | true    |  01.01.2023 | 1             |
+------+------------+-----------+---------+-------------+---------------+

```
 
### Задание 2

Необходимо реализовать web-приложение для работы с пространственными объектами.

Обеспечить следующие возможности.

1. Просмотр страницы с интерактивной картой и отображением местоположения всех точек.
2. Просмотр списка точек с атрибутивной информацией (номер по порядку, name) в табличном виде на странице с интерактивной картой.
3. Просмотр подробной информации о точке с отображением всех атрибутов (при клике на карте, а так же из списка объектов).

Примечания

- использовать библитеку для отображения пространственных данных - openlaers
- при реализаци таблицы использовать загрузку данных по API, пагинацию, реализовать функционал по сортировке и поиску
- использовать данные созданные в предыдущем задании
- запуск web-приложения в среде linux

Будет плюсом

- использование jquery, webpack
- использование фреймворка Django
