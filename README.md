# Тестовое задание на позицию frontend-разработчик
 
# Практичесое задание

Необходимо реализовать web-приложение для работы с пространственными объектами.

Обеспечить следующие возможности.

1. Просмотр страницы с интерактивной картой и отображением местоположения всех дорог (набор данных в road.csv).
2. Просмотр списка ЗУ с атрибутивной информацией (номер по порядку, name, area) в табличном виде на странице с интерактивной картой.
3. Просмотр подробной информации о ЗУ с отображением всех атрибутов (при клике на объект, а так же из списка объектов) и подсветкой расположения на интерактивной карте.

Примечания

- использовать библитеку для отображения пространственных данных - openlaers
- при реализаци таблицы использовать загрузку данных через запросы к серверу, пагинацию
- данные для заполнения находятся в файле road.csv
- запуск web-приложения в среде linux

Будет плюсом

использование jquery, webpack
использование фреймворка Django
